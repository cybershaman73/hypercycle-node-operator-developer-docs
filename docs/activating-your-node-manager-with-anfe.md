# Activating your Node Manager with ANFE

## <mark style="color:purple;">**Activating with an ANFE**</mark> <a href="#lhyhq54d6h4p" id="lhyhq54d6h4p"></a>

1. Connect a wallet containing ANFE using the wallet connect button top right side of the Node Manager home page. Make sure the <mark style="color:yellow;">BASE</mark> network is active in the wallet.
   1. MetaMask and Coinbase wallets are directly supported with the Node Manager's wallet connect. If you are using another wallet, click on <mark style="color:yellow;">Other Wallets</mark> and scan the QR-Code with a compatible mobile wallet.&#x20;
2. You will see your ANFEs listed under <mark style="color:yellow;">All Licenses</mark>:

![](../assets/cdff022447-0.png)

3. Click on *<mark style="color:green;">**Register**</mark>* for the ANFE you want to assign to the node. Wallet will prompt you for a confirmation. You will see this message if successful:

![](../assets/5576f2c1af-1.png)

4. Delegation of the ANFE will take a little while. Refresh your node manager page after an hour and click on the <mark style="color:yellow;">**Info**</mark> tab. It will display your license status and summary.

![](../assets/fd8583b3e4-2.png)
